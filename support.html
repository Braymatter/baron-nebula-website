Support

Something wrong?

The fastest way to tell us is from inside the game.

Report a bug

Press F8, or open the pause menu and choose Report a bug. Type what happened in a line and send it: it reaches us with the game's recent log, so we can see what led up to it. If the game crashes, it sends a report by itself the next time you start it (see Privacy for what's in one).

Ask a question

Join the Discord, or write to baron.nebula@gmail.com.

Common problems

The game runs slowly
In Settings › Graphics, set Fog to Performance, Effects to Reduced, and lower Particles.
The screen is black or flickers
Try another Renderer in Settings › Graphics, then restart the game to use it.
I can't join online games
Online play needs the latest build. Update the game from Steam or itch.io and try again.
